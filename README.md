# 字幕工坊 Windows 测试版

当前内测版本：**0.4.4**。适用于 Windows 10/11 x64。

[0.4.4 发布记录](https://github.com/chuendage/video-editor-releases/releases/tag/beta-v0.4.4)

本版为 **Pre-release**，合并新版 Qt 工作台、任务记录删除、定稿字幕时间轴修复及字幕 / 配音 / 视频统一对齐，包含完整桌面批量工作流。员工可免登录下载，无需安装 Python。

- [下载安装包（推荐）](https://github.com/chuendage/video-editor-releases/releases/download/beta-v0.4.4/VideoWorkflow-0.4.4-setup.exe)：双击安装，按向导完成后从快捷方式启动。
- [下载便携版](https://github.com/chuendage/video-editor-releases/releases/download/beta-v0.4.4/VideoWorkflow-0.4.4-windows-x64-portable.zip)：完整解压到可写目录，双击 `VideoWorkflow.exe`，保留整个目录。

两种包均包含 Python 运行时、Faster-Whisper small 多语言模型、FFmpeg 和 CapCut SDK。首次本地识别无需联网下载模型；云端识别、校正翻译和配音仍需要联网。`update.zip` 与 `version.json` 由软件升级器使用，首次安装无需单独下载。

## 0.4.4 更新

- **新版工作台**：七个功能页改为侧边导航，顶部功能搜索支持 Ctrl+K，深色卡片与蓝色主按钮；任务支持卡片 / 紧凑列表。开始、重试失败、打开产物是工具栏一级按钮，其他操作在四组菜单中。右侧环境状态仅在验证后显示就绪。
- **定稿字幕时间轴**：从剪映导入校对、合并后的 UTF-8 SRT，配音和草稿共用同一份定稿分段。旧分段音频不能套到新字幕；逐条校验音频与字幕起点，误差达到 0.5 秒中止。重叠时才换轨，空闲轨道复用。
- **统一对齐**：在“批次设置”配置配音变速 / 裁剪、原声、无字幕片段删留、视频变速和慢放补帧。先调整配音，超限后由视频慢放分担；每条视频独立计算。只预览第一条，确认后整批自动跑，可存为默认模板。
- **仅删除记录**：“更多 → 删除选中任务”保留原视频、字幕、配音、草稿与成片；运行中需先取消并等待停止。

逐条 TTS 默认 8 并发、失败退避、CapCut 熔断及 Edge-TTS 降级保持。音频变速使用 atempo，视频变速保留为可编辑草稿属性；慢放补帧由 FFmpeg 生成素材，不声称已启用未经验证的剪映内置补帧开关。

旧任务使用定稿：选中任务 →“字幕与配音 → 导入定稿字幕”→ 从“配音”步骤重跑 →“批次设置”核对统一对齐 →“草稿与导出 → 生成 / 重建选中草稿”→ 检查首条预览并确认。改语言或音色时创建新任务。

## 主要功能

- **批量任务**：添加视频、递归导入文件夹、拖入路径；按视频 × 目标语言创建独立任务。可填写改错/翻译提示词、术语表，保存项目，开始、暂停派发、取消、续跑及从指定步骤重跑。
- **服务与配音设置**：配置 LLM 和四路 TTS，拖动调整 CapCut → 火山 → MiniMax → Edge 的降级顺序，设置开关及各服务的语言音色。密钥写入 Windows 凭据库；新增或更改服务后先试音再保存。
- **CapCut 直连**：SDK 随包运行，每台员工电脑直接请求云端，无需中央服务地址或密钥；非官方接口默认关闭；启用后默认补齐 Edge 兜底，可在设置中关闭自动兜底。
- **剪映草稿**：五步完成后可生成草稿，包含可编辑字幕、旁白、原生滤镜及 BGM；BGM 从 0 铺满/循环全片，默认 −18 dB。
- **剪映与导出**：配置程序、草稿和成片路径、分辨率/帧率/码率；提供“一键导出自检”，通过后才能串行批量导出。

## 首次测试

1. 在“软件更新”核对当前版本为 **0.4.4**。
2. “服务与配音设置”：填写 LLM 地址、模型并保存密钥；配置目标语言音色，试音成功后启用保存。CapCut 英语示例 `en_us_006|7114563482518819329`，Edge 英语示例 `en-US-AriaNeural`；其他语言需要对应音色。付费服务试音可能计费。
3. “剪映与导出”：选择实际 `JianyingPro.exe`、草稿根目录、成片目录及账号可用的滤镜；在“识别与 BGM 设置”选择背景音乐。
4. “批量任务”：先用一个有权处理的短视频测试识别 → 校正改错 → 翻译 → 配音 → 识别配音字幕 → 草稿。双击任务查看实际提供商、降级原因及每步产物。
5. 保存自己的剪映编辑并回到首页，执行“一键导出自检”；通过后再测试批量导出。最后执行 20 个视频 × 2 种语言的稳定性验证。

**当前自动导出路径不支持剪映 7 及以上。** 此类版本可生成草稿并手动导出；剪映 6 及以下也必须通过本机真实自检，不能仅凭版本号认定支持。Windows 和剪映的实际组合仍待员工验收。

取消会停止自动操作并保留剪映进程。若剪映已开始渲染，请在剪映内检查并手动取消；取消或失败后需重新自检。旁白长于视频时阻止自动导出，先在剪映中补足画面。

## 已有版本升级

已有 0.2.0 / 0.3.0 / 0.4.0 / 0.4.1 / 0.4.2 / 0.4.3 用户先备份安装目录的 `userdata/`，进入“软件更新”，选择“测试通道”并保存，点击“检查更新”，再点击“下载并安装，完成后重启”。升级器校验签名和 SHA-256，新版本启动失败时恢复上一版本。
